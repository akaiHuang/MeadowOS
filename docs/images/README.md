# Screenshot provenance

These are unmodified 1920 × 1080 PNG captures of real native Linux windows in a
fresh ARM64 CI container at source `d4477c88ba6ac8c593b3fa671bf31f6a822db0b8`.
They contain demo work files only. No provider key was configured, no model
request was sent, and no maintainer desktop or private conversation was used.

- `desktop.png`: GTK Shell, native Files and Terminal.
- `chat.png`: the existing Shell chat before Inception setup, with a disabled
  send control and the real configuration notice.
- `settings.png`: native Settings; displayed hardware/kernel values describe
  the CI container/runner, not the maintainer's computer.
